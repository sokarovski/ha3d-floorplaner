# Design-system implementation examples

Updated: 2026-11-16.

Status: illustrative excerpts. The Toolbox and Button excerpts match the implementation as of the Updated date; the source in `src/design-system/` is authoritative. The [design-system specification](README.md) owns requirements and conventions.

The token excerpt deliberately shows only a subset. Implementation must emit every semantic role in both themes and compile all component styles in the shared Tailwind context. The proposed Button contract is one possible way to keep styling in data selectors; runtime numeric styling policies should be consistent with the owning component's needs.

## Source layout

The actual layout of `src/design-system/` (2026-11-16). Every component has its own folder with its `.tsx` file and its `.tw.css` file; small typed helpers sit next to it.


## Toolbox component

```tsx
import type { ReactElement, ReactNode } from "react";

type ToolboxProps = Readonly<{
  children: ReactNode;
  label: string;
  orientation?: "vertical" | "horizontal";
  /**
   * Buttons pinned to the end of a vertical toolbox (owner, Phase 5 follow-up: the camera buttons). When the
   * toolbox is too short, the tools above scroll and the footer stays.
   */
  footer?: ReactNode;
}>;

export const Toolbox = ({
  children,
  label,
  orientation = "vertical",
  footer,
}: ToolboxProps): ReactElement => (
  <aside
    aria-label={label}
    role="toolbar"
    aria-orientation={orientation}
    data-toolbox=""
    data-toolbox-vertical={orientation === "vertical" ? "" : undefined}
    data-toolbox-horizontal={orientation === "horizontal" ? "" : undefined}
  >
    <div data-toolbox-tools="">{children}</div>
    {footer === undefined ? null : (
      <div data-toolbox-footer="">
        <span data-toolbox-separator="" />
        {footer}
      </div>
    )}
  </aside>
);
```

## Button component

The Button wraps React Aria's `Button` (press, focus, and hover state come as its `data-*` attributes) and maps each variant to a data attribute.

```tsx
import type { ReactElement, ReactNode } from "react";
import { Button as AriaButton } from "react-aria-components";
import { Spinner } from "../Spinner/Spinner";

type ButtonProps = Readonly<{
  children: ReactNode;
  variant?: "primary" | "secondary" | "danger" | "ghost";
  size?: "sm" | "md";
  type?: "button" | "submit";
  disabled?: boolean;
  busy?: boolean;
  onPress?: () => void;
  "aria-label"?: string;
  autoFocus?: boolean;
}>;

export const Button = ({
  children,
  variant = "primary",
  size = "md",
  type = "button",
  disabled = false,
  busy = false,
  onPress,
  "aria-label": ariaLabel,
  autoFocus,
}: ButtonProps): ReactElement => (
  <AriaButton
    type={type}
    isDisabled={disabled || busy}
    isPending={busy}
    onPress={onPress}
    aria-label={ariaLabel}
    autoFocus={autoFocus}
    data-button=""
    data-button-primary={variant === "primary" ? "" : undefined}
    data-button-secondary={variant === "secondary" ? "" : undefined}
    data-button-danger={variant === "danger" ? "" : undefined}
    data-button-ghost={variant === "ghost" ? "" : undefined}
    data-button-sm={size === "sm" ? "" : undefined}
  >
    {busy ? <Spinner label="Working" /> : null}
    {children}
  </AriaButton>
);
```
